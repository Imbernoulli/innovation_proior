A probability attaches a number to one event, and every tool I have for a sequence of events still speaks that one-event language. The weak law says $P(|\bar X_n-\mu|>\varepsilon)\to 0$: at each large stage $n$, a deviation is improbable. That is a statement about the marginal distribution of $\bar X_n$, one $n$ at a time. The statement I actually need is of a different type. "Almost every real number in $[0,1]$ is normal" means that for almost every outcome, the event "the empirical digit frequency is still off at stage $n$" happens only finitely often — a statement about a *fixed* $\omega$ and the *entire infinite tail* of the sequence attached to it. Between "each $A_n$ is improbable" and "along almost every path the $A_n$ eventually stop" there is a gap that no amount of per-stage sharpening closes, and what I am given to close it with is only the sequence of marginal numbers $\{P(A_n)\}$ together with whatever structural fact I am willing to assume about how the $A_n$ relate.

The first thing is to name the target set exactly, because everything hinges on getting it right. "$\omega$ lies in infinitely many $A_n$" says: for every $n$ there is some $k\ge n$ with $\omega\in A_k$. A "for every $n$, there exists $k\ge n$" is an intersection of unions,
$$\{A_n \text{ i.o.}\}\;=\;\limsup_{n\to\infty}A_n\;=\;\bigcap_{n=1}^{\infty}\bigcup_{k=n}^{\infty}A_k,$$
and the name $\limsup$ is earned by the indicator identity $1_{\bigcap_n\bigcup_{k\ge n}A_k}=\lim_n\sup_{k\ge n}1_{A_k}=\limsup_n 1_{A_n}$. Its complement, "only finitely often", is $\bigcup_n\bigcap_{k\ge n}A_k^c$ — eventually $A_k^c$ forever. Written this way the inner union $B_n=\bigcup_{k\ge n}A_k$ is *decreasing* in $n$, which is the one structural gift the definition hands over for free.

Against that target the inherited toolkit is a set of pieces that individually stop short. Subadditivity bounds the probability that *some* event from stage $n$ on occurs, but says nothing about a limit of such stages. Continuity of $P$ along monotone sequences evaluates a limiting set as a limit of probabilities, but only once the finite stages can be evaluated. Independence turns an intersection into a product, but by itself carries no tail conclusion. Markov and Chebyshev, pushed to a fourth moment, deliver per-$n$ deviation probabilities that decay like $n^{-2}$ — fast, but still per-$n$. And there is a hard constraint any criterion must respect: on $\Omega=(0,1)$ with Lebesgue measure the nested events $A_n=(0,1/n)$ have $\sum_n P(A_n)=\sum_n 1/n=\infty$, yet $\limsup_n A_n=\bigcap_n(0,1/n)=\varnothing$. Large events, divergent total mass, and the bad event happens for no outcome eventually. So no criterion that reads only the numbers $\{P(A_n)\}$ can promise recurrence unconditionally.

What I propose is the pair of lemmas I will call the Borel–Cantelli dichotomy: the entire question is decided by the convergence or divergence of the single series $\sum_n P(A_n)$, with the two halves carrying asymmetric hypotheses. If $\sum_n P(A_n)<\infty$ then $P(\limsup_n A_n)=0$ — almost surely only finitely many $A_n$ occur — and this needs *nothing* about how the events relate. If the $A_n$ are independent and $\sum_n P(A_n)=\infty$ then $P(\limsup_n A_n)=1$ — almost surely infinitely many occur. Divergence alone does not suffice; the nested example is the witness, and independence is exactly what is needed to rule it out.

The convergent half falls straight out of the decreasing structure. Since $B_n\downarrow\limsup_n A_n$, continuity from above and then the union bound give
$$P\!\left(\limsup_n A_n\right)=\lim_{n\to\infty}P(B_n)=\lim_{n\to\infty}P\!\left(\bigcup_{k=n}^{\infty}A_k\right)\le \lim_{n\to\infty}\sum_{k=n}^{\infty}P(A_k)=0,$$
the last equality being nothing more than the definition of convergence: the tail of a convergent series vanishes. Both inequalities used are unconditional, which is why no hypothesis on the joint law appears. It is worth deriving the same conclusion a second way, because the second derivation explains *why* it is true. Let $N=\sum_{k=1}^{\infty}1_{A_k}$ count the events that occur along $\omega$. By Tonelli — expectation and sum commute freely for nonnegative terms — $E\,N=\sum_k E\,1_{A_k}=\sum_k P(A_k)$, so a convergent series says precisely that the *expected number of occurrences is finite*; and a nonnegative random variable with finite expectation is finite almost surely, since an infinite value on a set of positive probability would already make the mean infinite. Read this way the lemma is not a trick about limsups at all: a finite average count simply cannot tolerate an infinite count on a non-null set. That reading is what later makes the lemma usable as a bridge, since any application only has to exhibit summable per-stage probabilities.

The divergent half is where the work is. It suffices to show $P\!\left(\bigcap_{k=n}^{\infty}A_k^c\right)=0$ for each fixed $n$, since the complement of $\{A_n\text{ i.o.}\}$ is the countable union of these sets and a countable union of null sets is null. Independence of the $A_k$ passes to their complements, and independence is exactly the rule that factorizes an intersection; I keep it finite and pass to the limit by continuity from above, since $\bigcap_{k=n}^{N}A_k^c$ decreases in $N$:
$$P\!\left(\bigcap_{k=n}^{\infty}A_k^c\right)=\lim_{N\to\infty}\prod_{k=n}^{N}\bigl(1-P(A_k)\bigr).$$
Everything now rides on whether this product of factors just below $1$ collapses to $0$. It need not in general — if $\sum_k p_k<\infty$ the product $\prod_k(1-p_k)$ settles at a strictly positive limit — so divergence has to be the thing that drives it down, and I need to see the sum *inside* the product. The exponential is the unique function converting products into sums of exponents, $\prod_k e^{-p_k}=e^{-\sum_k p_k}$, so the bridge I want is the pointwise bound $1-x\le e^{-x}$. It holds for every real $x$: with $g(x)=e^{-x}-(1-x)$ one has $g(0)=0$ and $g'(x)=1-e^{-x}$, which is $\ge 0$ for $x\ge 0$ and $\le 0$ for $x\le 0$, so $g$ attains a global minimum of $0$ at the origin and is nonnegative everywhere, with equality only at $x=0$. The slack it costs is negligible in the regime that matters: at $x=0.3$ the two sides are $0.700$ and $0.741$, at $x=0.5$ they are $0.500$ and $0.607$, and the gap only becomes gross as $x\to1$ (at $x=1$, $0$ against $0.368$), whereas the interesting profiles have small $P(A_k)$. Applying it factor by factor with $x=P(A_k)$,
$$\prod_{k=n}^{N}\bigl(1-P(A_k)\bigr)\le\prod_{k=n}^{N}e^{-P(A_k)}=\exp\!\left(-\sum_{k=n}^{N}P(A_k)\right),$$
and as $N\to\infty$ the exponent tends to $-\infty$, because chopping the finite front $\sum_{k<n}P(A_k)$ off a divergent series leaves a still-divergent tail. So the bound tends to $0$, every $\bigcap_{k\ge n}A_k^c$ is null, and $P(\limsup_n A_n)=1$. The inequality $1-x\le e^{-x}$ is the entire hinge: it converts a product I cannot evaluate into the exponential of the sum I have a hypothesis about.

Independence enters at exactly one line — the factorization — and it is instructive to see how badly that line fails without it. For the nested $A_n=(0,1/n)$ the complements $A_k^c=[1/k,1)$ *increase* with $k$, so the tail intersection collapses onto its first member: $\bigcap_{k=n}^{N}A_k^c=A_n^c$ for every $N\ge n$, and therefore $P\!\left(\bigcap_{k=n}^{\infty}A_k^c\right)=1-1/n$, a quantity that does not decay in $N$ at all and in fact climbs to $1$ as $n$ grows. That is exactly why $\{A_n\text{ finitely often}\}=\bigcup_n\bigcap_{k\ge n}A_k^c$ has probability $1$ here and $P(\limsup_n A_n)=0$. The product that factorization would have produced telescopes to something entirely different: $\prod_{k=n}^{N}\bigl(1-1/k\bigr)=\tfrac{n-1}{n}\cdot\tfrac{n}{n+1}\cdots\tfrac{N-1}{N}=\tfrac{n-1}{N}\to 0$. The two are not approximately equal and slightly off; for large $n$ they sit at opposite ends of $[0,1]$, one saying "the tail of complements is null, the bad event recurs surely" and the other saying "the tail of complements carries almost all the mass, the bad event never recurs". Take the very same profile $P(A_k)=1/k$ and make the events independent, and the product formula becomes legitimate, equals that same $(n-1)/N\to 0$, and now correctly drives the conclusion to $P(\limsup A_n)=1$; my exponential bound reproduces it more crudely, giving $\exp(-\sum_{k=2}^{N}1/k)\approx 0.00153$ at $n=2$, $N=1000$ against the exact $1/1000=0.001$ — loose by about half, correctly above the truth, correctly heading to zero. Identical marginals, opposite verdicts, and the only thing that changed is whether the intersection factors. Independence is the working hypothesis of the second lemma, not a convenience.

Mutual independence is nevertheless more than the argument consumes, and the qualitative conclusion is weaker than the count deserves, so both edges can be pushed. Suppose only that the $A_m$ are *pairwise* independent, i.e. the indicators $X_m=1_{A_m}$ are uncorrelated, and let $S_n=\sum_{m\le n}X_m$ with $ES_n=\sum_{m\le n}P(A_m)\to\infty$. Uncorrelatedness makes the variance additive, and $\operatorname{Var}(X_m)\le EX_m^2=EX_m=P(A_m)$ for an indicator, so $\operatorname{Var}(S_n)\le ES_n$ — the variance is dominated by the mean, which is the whole reason a relative-scale Chebyshev bite works:
$$P\bigl(|S_n-ES_n|>\delta\,ES_n\bigr)\le\frac{\operatorname{Var}(S_n)}{(\delta ES_n)^2}\le\frac{1}{\delta^2\,ES_n}\longrightarrow 0 .$$
That is convergence in probability, the weak side again, so I upgrade it by choosing a subsequence along which these bounds are *summable* and then filling the gaps by monotonicity of $S_n$. Take $n_k=\inf\{n:ES_n\ge k^2\}$ and $T_k=S_{n_k}$; each increment of $ES_n$ is at most $1$, so the overshoot is at most $1$ and $k^2\le ET_k\le k^2+1$, whence $P(|T_k-ET_k|>\delta ET_k)\le 1/(\delta^2k^2)$, which is summable. The convergent half — the one needing no independence at all — then says these deviations happen finitely often, so $T_k/ET_k\to 1$ a.s. for each $\delta$, hence a.s. For $n_k\le n<n_{k+1}$, monotonicity of both $S_n$ and $ES_n$ sandwiches
$$\frac{ET_k}{ET_{k+1}}\cdot\frac{T_k}{ET_k}\;\le\;\frac{S_n}{ES_n}\;\le\;\frac{T_{k+1}}{ET_{k+1}}\cdot\frac{ET_{k+1}}{ET_k},$$
and the block ratio is harmless because $ET_{k+1}/ET_k\le\{(k+1)^2+1\}/k^2=1+2/k+2/k^2\to1$ — this is exactly why the subsequence was chosen to grow like $k^2$ rather than geometrically, so that consecutive means are asymptotically equal and no gap is lost. Both bounds tend to $1$, so
$$\frac{S_n}{\sum_{m=1}^{n}P(A_m)}\xrightarrow{\ \text{a.s.}\ }1 .$$
This is strictly stronger and strictly more general: pairwise independence suffices, and the conclusion is not merely "infinitely often" but that the count is asymptotic to its mean, with infinitely-often falling out as the crudest consequence since $ES_n\to\infty$.

The other edge is to drop independence entirely and ask what quantitative hypothesis the engine really needs. The pairwise proof leaned only on the second moment of the count being small relative to the square of its mean, so the bare version is a Cauchy–Schwarz bound: writing $S_n=S_n1_{\{S_n>0\}}$ gives $(ES_n)^2\le ES_n^2\,P(S_n>0)$ with $ES_n^2=\sum_{1\le j,k\le n}P(A_j\cap A_k)$, and since $\{S_n>0\}=\bigcup_{k\le n}A_k$ increases while $\bigcup_{k\ge m}A_k\supseteq\bigcup_{m\le k\le n}A_k$, passing to the $\limsup$ in $n$ and then $m\to\infty$ yields the Kochen–Stone lower bound
$$P\!\left(\limsup_n A_n\right)\ \ge\ \limsup_{n\to\infty}\frac{\bigl(\sum_{k\le n}P(A_k)\bigr)^2}{\sum_{1\le j,k\le n}P(A_j\cap A_k)}$$
whenever $\sum_k P(A_k)=\infty$. Independent events (or merely $P(A_j\cap A_k)\le P(A_j)P(A_k)$ off the diagonal with the diagonal controlled) make the denominator $\approx(\sum_k P(A_k))^2$ and the ratio tend to $1$: the second lemma is the corner of this statement, and in general a ratio $\alpha>0$ buys recurrence with probability at least $\alpha$.

Cashing the dichotomy out on the question that motivated it, the strong law of large numbers under a fourth moment comes almost for free, because the fourth moment is exactly what makes deviation probabilities summable. For i.i.d. $X_i$ with $EX_i=\mu$ and $EX_i^4<\infty$, subtract the mean so $\mu=0$ and expand $ES_n^4=\sum_{i,j,k,\ell}E[X_iX_jX_kX_\ell]$; independence and $EX_i=0$ kill every term in which some index appears exactly once, leaving the $n$ terms $EX_i^4$ and the $3n(n-1)$ terms $E[X_i^2X_j^2]=(EX_1^2)^2$ with $i\ne j$, so
$$ES_n^4=nEX_1^4+3n(n-1)(EX_1^2)^2\le Cn^2,\qquad P(|S_n|>n\varepsilon)\le\frac{ES_n^4}{(n\varepsilon)^4}\le\frac{C}{n^2\varepsilon^4},$$
which is summable in $n$. The convergent half gives $P(|S_n|>n\varepsilon\ \text{i.o.})=0$ for each $\varepsilon$, so $|S_n|\le n\varepsilon$ eventually and, $\varepsilon$ being arbitrary, $S_n/n\to\mu$ almost surely. The fourth moment is not decoration: a second moment alone yields only $n^{-1}$ decay, which is not summable, and the bridge would not carry. The divergent half runs the same machine backwards to show a finite mean is necessary. If $E|X_i|=\infty$ then, from $E|X_1|=\int_0^\infty P(|X_1|>x)\,dx\le\sum_{n\ge0}P(|X_1|>n)$, the series $\sum_n P(|X_n|\ge n)$ diverges; the events $\{|X_n|\ge n\}$ are independent, so $|X_n|\ge n$ infinitely often almost surely. That is incompatible with $S_n/n$ converging to a finite limit, since $S_n/n\to L$ forces $X_n/n=S_n/n-\frac{n-1}{n}\cdot S_{n-1}/(n-1)\to 0$. The two halves of the dichotomy are therefore the two directions of "finite mean $\Leftrightarrow$ strong law".

The lemmas are theorems and a simulation proves nothing; what it can do is *exhibit* the dichotomy on sampled trajectories of independent events, and I keep those two roles strictly separate. Drawing $1_{A_n}\sim\mathrm{Bernoulli}(P(A_n))$ independently out to $N=200000$ from seed $0$, the summable profile $P(A_n)=1/n^2$ produces one occurrence, at index $1$, and then silence for the remaining $199999$ stages, which is what an expected total count of $\sum_n 1/n^2\le\pi^2/6\approx1.64$ predicts; the divergent profile $P(A_n)=1/n$ produces $10$ occurrences with the last at index $48750$, against an expected count $\sum_{n\le N}1/n\approx\ln N+\gamma\approx12.78$, and no sign of stopping. The running-frequency snapshots are the honest part: $S_n/E[S_n]$ reads $0.802,\,0.817,\,0.827,\,0.782$ at $n=10^3,10^4,10^5,2\times10^5$, hovering near $0.8$ rather than tightening on $1$. That is not a failure of the pairwise sharpening but a measure of how mild it is at finite $n$, since $\operatorname{Var}(S_n/ES_n)\le 1/ES_n$ puts the standard deviation of the ratio at about $1/\sqrt{12.78}\approx0.28$; $ES_n$ grows like $\ln n$, the slowest divergence there is, so pinning the ratio near $1$ on a single path would need $ES_n$ in the hundreds and hence an astronomical horizon. The grid scan of $(1-x)-e^{-x}$ on $[0,1]$ returns a maximum of $0.0\mathrm{e}{+}00$, consistent with the convexity argument that the divergent half rests on.

```python
import math, random

def last_occurrence_and_count(prob_fn, N, seed=0):
    """One realization of independent events A_1..A_N with P(A_n)=prob_fn(n).
    Returns (number that occurred, largest index that occurred)."""
    rng = random.Random(seed)
    occurred, last = 0, 0
    for n in range(1, N + 1):
        if rng.random() < prob_fn(n):          # draw 1_{A_n} ~ Bernoulli(P(A_n))
            occurred += 1
            last = n
    return occurred, last

def running_frequency(prob_fn, N, seed=0):
    """S_n / E[S_n] for the divergent profile (S_n / sum_{k<=n} P(A_k) -> 1)."""
    rng = random.Random(seed)
    S, ES, snap = 0.0, 0.0, {}
    for n in range(1, N + 1):
        p = prob_fn(n)
        ES += p                                 # E[S_n] = sum_{k<=n} P(A_k)
        if rng.random() < p:
            S += 1
        if n in (1000, 10000, 100000, N):
            snap[n] = S / ES
    return snap

if __name__ == "__main__":
    # hinge of the divergent half: 1 - x <= e^{-x}, i.e. (1-x) - e^{-x} <= 0
    worst = max((1 - x) - math.exp(-x) for x in [i / 100 for i in range(101)])
    print(f"max of (1-x) - e^(-x) on [0,1]: {worst:.1e}   (<= 0 confirms 1-x <= e^(-x))")

    N = 200000
    summable  = lambda n: 1.0 / (n * n)         # sum 1/n^2 < inf  -> finitely often
    divergent = lambda n: 1.0 / n               # sum 1/n  = inf, indep -> infinitely often
    oc, lc = last_occurrence_and_count(summable, N)
    od, ld = last_occurrence_and_count(divergent, N)
    print(f"P(A_n)=1/n^2 : occurrences={oc:6d}, last index seen={lc:7d}   (settles -> finite)")
    print(f"P(A_n)=1/n   : occurrences={od:6d}, last index seen={ld:7d}   (keeps recurring)")
    print("divergent S_n / E[S_n] (should approach 1):",
          {n: round(v, 3) for n, v in sorted(running_frequency(divergent, N).items())})
```
